# phan-tich-cong-thuc — script và dữ liệu

Thư mục này giữ **script `.py` và dữ liệu máy đọc** (`.csv`, `.json`) của phần
nghiên cứu công thức. Script ghi kết quả vào chính thư mục này nên không di
chuyển được.

📄 **Báo cáo đọc được đã chuyển sang**
`Hướng dẫn build project/bao-cao-cong-thuc/`.

📐 **Công thức đang chạy** mô tả ở
`Hướng dẫn build project/02_CONG_THUC_SO_LUONG.md`.

⚠️ **Không đụng vào công thức, dự báo hay hệ số trước Phase G** (QĐ-06).

Lưu ý: `*.csv` và `*.json` trong thư mục này **không commit** — chúng chứa tên
khoa và sản lượng thật (xem `.gitignore`).
