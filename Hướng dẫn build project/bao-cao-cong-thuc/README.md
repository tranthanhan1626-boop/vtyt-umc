# Báo cáo nghiên cứu công thức

Kết quả nghiên cứu và backtest để chọn công thức số lượng, làm tháng 8/2026.
Công thức **đang chạy** được mô tả ở `../02_CONG_THUC_SO_LUONG.md` — đọc file
đó trước.

| File | Nội dung |
|---|---|
| `BAO_CAO_THANG_0_VA_CONG_THUC_MOI.md` | Báo cáo chính: vấn đề tháng 0 và công thức mới |
| `KET_QUA_CHON_CONG_THUC_DOT_NAY.md` | Kết quả chấm điểm chọn công thức cho đợt này |
| `KET_QUA_NGHIEN_CUU_HIEN_DAI.md` | Khảo sát công thức hiện đại 2024–2026 |
| `KET_QUA_NGHIEN_CUU_THUA_GIAN_DOAN.md` | Nghiên cứu chuỗi thưa/gián đoạn |
| `DE_AN_DU_BAO_NHU_CAU_VA_DU_TRU_MUA_THAU_VTYT.docx` | Đề án dự báo nhu cầu |

**Script sinh ra các báo cáo này nằm ở `phan-tich-cong-thuc/` tại gốc repo**,
cùng với dữ liệu `.csv`/`.json` chúng xuất ra. Script không chuyển vào đây vì
chúng ghi kết quả bằng đường dẫn tuyệt đối tới thư mục của chính chúng.

⚠️ **Không đụng vào công thức, dự báo hay hệ số trước Phase G** (QĐ-06).
